# Future Launcher

An Android launcher built with Kotlin and Jetpack Compose.

## Build the APK
Open the **Actions** tab in this repository and run **Build FutureLauncher APK** (or push a change under `FutureLauncher/`). Download the `FutureLauncher-APK` artifact from the completed workflow run.

## Use
Install the APK, press Home, and choose **Future Launcher** as the default launcher.

- Swipe up to open the app drawer.
- Long-press an app to pin it to the dock or open its app info.
- Tap the gear icon to change icon shape, accent color, and icon size.

The project is stored in this repository under `FutureLauncher/` so it does not replace the existing Sandie or Zero Launcher projects.
